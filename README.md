# Virelle – Jewelry Webshop


## Description
This webshop was developed as part of a final project in web development.
The purpose of the project was to create a visual and functional e-commerce experience with a focus on user interface, navigation, and shopping cart logic.
The webshop simulates how a real online store works but does not store any data permanently.
This project focuses on frontend development and user interface, and therefore does not include a backend or database.


## Features
-	Browse products by category
-	Navigate between different pages
-	View product details in a modal window.
-	Add products to the shopping cart.
-	Increase or decrease the quantity of products in the cart
-	View the total price in the cart.
-	Responsive design for mobile, tablet, and desktop


## Tech Stack
-	HTML
-	CSS
-	JavaScript

No frameworks or libraries (such as React) were used.


## Getting Started/ Installation
The project requires no installation.

To run the webshop:
1.	Download or clone the repository from GitHub
2.	Open the `index.html` file in a web browser.

Alternatively, the project can be run via GitHub Pages.


## Usage
After opening the website, the user can navigate between product categories using the hamburger menu or the buttons on the homepage.
Products can be added to the shopping cart, where the total price is displayed.
In the cart, the user can increase or decrease the quantity of each product.


## Project Structure
The project consists of:
-	`index.html` – main homepage
-	`catalog.html` – product listing page
-	CSS file for styling
-	JavaScript file handling:
  -	Product display
  -	Navigation
  -	Shopping cart logic
-	`/img` – image assets.


## Limitations
-	The shopping cart is not saved when the page is reloaded.
-	No user accounts or checkout system.
-	No backend or database.


## Possible Improvements
-	Save cart using localStorage.
-	Refactor the code using classes (OOP).
